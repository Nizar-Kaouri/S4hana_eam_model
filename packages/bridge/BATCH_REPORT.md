### Design decisions (please confirm)

1. **One bundle = one prefix and one package.** Products keep their own prefixes in the repo; the bundle
   rewrites all of them. Mixing per-product prefixes in one customer system is not supported.
2. **Bridges reference module objects only**, never another product's link views, so a bridge never
   depends on whether an intra-product link was shipped.
3. **No bridge for PS yet** (maintenance order ↔ WBS element) and none for QM ↔ EAM notifications: the
   join fields are not confirmed. To be added after the release check.

### Open risks

- **BRG-002:** several equipment on one asset repeat the asset values; totals over equipment overstate.
- **BRG-D01:** `ZBRG_R_EquipmentAssetValue` inherits two roles (equipment + asset balance) on a join;
  the inherited role elements must be projected under the same names, else activation fails.
