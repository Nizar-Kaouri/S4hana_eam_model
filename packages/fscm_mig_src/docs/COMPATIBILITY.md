# Compatibility

Source: Classic ECC credit management, FSCM Credit/Collections/Dispute Management, or S/4HANA successors; choose the exact path.

Classic source CDS requires an administrative NetWeaver 7.40 SP08+ stack. Target view entities assume S/4HANA 2025 on-premise/private cloud. Native exports may come from separate applications, and are not obtained by installing these stages. Public Cloud custom ABAP table deployment is not assumed. Native target interfaces must be confirmed for the chosen release.
