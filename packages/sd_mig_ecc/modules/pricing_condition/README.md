# Pricing condition records and scales


Export every configured condition access table (Axxx or customer tables) at its actual DDIC key and link KNUMH to KONH/KONP and scales. KONH alone loses the customer/material/sales-area access key; the configured access export is mandatory. Include supplements, exclusions, deletion, validity, calculation-type-specific percentages/currencies/units and scale type. Never confuse master condition records with document conditions (KONV/PRCD_ELEMENTS), or divide every rate by the same factor.

## Deutsche Anleitung

Alle konfigurierten Konditionszugriffstabellen mit tatsächlichem DDIC-Schlüssel exportieren und KNUMH mit KONH/KONP/Staffeln verknüpfen. KONH allein verliert Kunden-/Material-/Vertriebsbereichsschlüssel. Ergänzungen, Ausschlüsse, Löschung, Gültigkeit, Berechnungsart, Währungen/Einheiten und Staffelart prüfen. Stammkonditionen nicht mit Belegkonditionen verwechseln; keinen universellen Ratenfaktor anwenden.

See customer/coverage-requirements.json, source mapping and the native DDIC preflight. No SAP activation or posting test has run.
