### Design decisions (please confirm)

1. **Open order = not technically completed** (PP-003). The fallback is the system status TECO / DLV.
2. **Operations depend on the order module** and take type, material, plant and MRP controller over the order association.
3. **BOM items keep all change versions**; only deleted items are filtered in the cube. A "valid today" filter is a refinement.
4. **Work center is a plain field**; no PP work center module (EAM already has one; a shared module comes with the links).
