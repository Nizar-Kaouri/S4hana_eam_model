### Design decisions (please confirm)

1. **Actual costs only, from the Universal Journal.** Plan, budget and commitment values are a later refinement.
2. **Settlement is shown separately** (`BusinessTransactionType` 'KOAO'), so cost before settlement stays visible after month-end settlement.
3. **Project and WBS element are separate modules** without a dependency; the project → WBS association comes with the link views.
4. **All ledgers are kept**; the queries filter by ledger.
