# Native Quellextraktion

EWM, TM, FSCM und EHS liefern native Quellstrukturen mit B → I → C. Nur das SOURCE-Archiv im Quellsystem installieren. Umfang und offene Strukturen stehen in customer/native-coverage.json des jeweiligen Pakets. Keine Zielvergleichskomponente und keine Buchungsimplementierung enthalten.
